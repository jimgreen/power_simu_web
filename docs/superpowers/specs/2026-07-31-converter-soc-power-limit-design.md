# 学员台变流器 SOC 分段功率限额设计

## 1. 目标

在学员台新能源实时控制模块中，将 ACDC 变流器随储能 SOC 变化的送电功率上限从程序硬编码改为按模型持久化的可配置参数，并在新能源控制页面提供弹窗编辑入口。

配置由学员台服务端统一保存和执行。同一模型的多个 WEB 页面读取同一份配置，页面刷新和 WEB 服务重启后配置仍然有效。

## 2. 配置模型

SOC 固定划分为十个区间，每个区间宽度为 10%。配置字段使用十个比例值组成的数组：

```json
{
  "converterSocPowerLimits": [0.0, 0.0, 0.2, 0.4, 0.4, 0.5, 0.6, 0.8, 0.8, 1.0]
}
```

数组索引与 SOC 区间的对应关系如下：

| 索引 | SOC 区间 | 默认功率上限 |
| ---: | --- | ---: |
| 0 | 0%-10% | 0% |
| 1 | 10%-20% | 0% |
| 2 | 20%-30% | 20% |
| 3 | 30%-40% | 40% |
| 4 | 40%-50% | 40% |
| 5 | 50%-60% | 50% |
| 6 | 60%-70% | 60% |
| 7 | 70%-80% | 80% |
| 8 | 80%-90% | 80% |
| 9 | 90%-100% | 100% |

每个值只能是 `0.0, 0.1, 0.2, ..., 1.0` 之一，并且必须从低 SOC 到高 SOC 单调不下降。

## 3. 边界规则

- SOC 精确落在 10% 边界时进入后一档。
- SOC 为 20% 时使用 20%-30% 档。
- SOC 为 30% 时使用 30%-40% 档。
- SOC 为 90% 时使用 90%-100% 档。
- SOC 小于 0 时按第一档处理。
- SOC 大于 100% 时按最后一档处理，以保留异常实时 SOC 并继续使用最末档限额。
- SOC 缺失或不是有限数值时维持现有数据质量处理，不通过该配置绕过闭环下发限制。

## 4. 后端行为

`RenewableControlSettings` 增加 `converter_soc_power_limits` 配置，并通过现有新能源控制状态文件按模型持久化。

读取旧配置文件时，如果不存在新字段，则自动使用默认十段配置，不要求迁移旧文件。更新配置时，后端必须验证：

1. 输入为长度恰好等于 10 的数组。
2. 每个值为 0%-100% 范围内的 10% 整数档位。
3. 数组单调不下降。

任何一项不满足时，更新请求失败，原配置保持不变，持久化文件不被覆盖。

自动控制使用当前 SOC 命中的比例乘以所有有效 ACDC 变流器的原始并联容量，得到本轮允许的送电功率幅值。自动目标范围为：

```text
[-SOC 分档功率限额, 0]
```

负值表示直流侧向交流侧送电，正值表示交流侧向直流侧倒送。自动策略继续禁止正值目标。若实时功率已经超出当前 SOC 限额，目标直接限制到合法边界，不等待普通步长逐步收敛。

## 5. WEB 接口与状态同步

继续使用现有接口：

```text
GET  /api/trainee/renewable-control
POST /api/trainee/renewable-control
```

GET 响应中的 `settings` 增加 `converterSocPowerLimits`。保存弹窗时，前端调用 `update_settings`：

```json
{
  "action": "update_settings",
  "settings": {
    "converterSocPowerLimits": [0.0, 0.0, 0.2, 0.4, 0.4, 0.5, 0.6, 0.8, 0.8, 1.0]
  }
}
```

服务端保存成功后返回完整控制状态。多个页面后续轮询该状态时自动取得相同配置。实时控制运行期间允许保存，新配置从下一次控制计算开始生效。

## 6. 人机界面

新能源控制页的“参数配置”区域增加 `变流器 SOC 限额` 按钮。按钮打开原生 `dialog` 弹窗，沿用学员台现有对话框样式。

弹窗包含十行固定区间列表。每行左侧显示 SOC 范围，右侧使用下拉框选择 `0%, 10%, ..., 100%`。SOC 区间不可编辑，也不能增加或删除。

操作包括：

- `取消`：关闭弹窗，不修改后台配置。
- `保存`：前端先校验十项完整性、档位合法性和单调性，再调用后台接口。
- 右上角关闭按钮和点击对话框背景等同于取消。

若校验失败，弹窗内显示首个错误区间并保留当前输入。保存期间禁用保存按钮，防止重复请求。保存成功后关闭弹窗，新能源控制状态和当前策略立即重新渲染。

## 7. 指标与日志

控制计划继续输出原始变流器容量、当前 SOC 分档比例和实际限额。决策日志明确记录：

- 当前储能 SOC。
- 命中的 10% SOC 区间。
- 该区间配置的功率上限比例。
- 原始并联容量。
- 本轮实际送电功率限额。
- 自动控制允许的目标范围。

设备策略表中的“可用边界”继续显示应用 SOC 分档后的实时功率限额。

## 8. 测试与验收

后端测试覆盖：

- 默认十段配置及完整 10% 边界。
- 精确边界进入后一档。
- 低于 0 和高于 100% 的处理。
- 非十档、数组长度错误和非单调配置被拒绝。
- 配置更新、持久化和重启加载。
- 同一模型共享配置，不同模型配置隔离。
- SOC 限额和禁止倒送同时生效。

前端测试覆盖：

- 页面存在入口按钮和设置弹窗。
- 弹窗固定展示十个 SOC 区间。
- 功率上限只能选择 10% 档位。
- 前端拒绝非单调配置。
- 保存请求包含完整十段配置。
- 后端返回配置后，弹窗和页面状态正确同步。

浏览器验收覆盖桌面宽度和窄窗口，确认弹窗内容不溢出，十段列表过高时可在弹窗内部竖向滚动。

## 9. 非目标

- 不允许用户自行增加、删除或改变 SOC 区间。
- 不修改模拟台的人工遥调和遥控优先级。
- 不用该配置拒绝人工指令；该限额只约束学员台后台新能源自动控制策略。
- 不改变现有新能源步长、变流器步长、柴发死区和 SOC 死区参数的含义。
