# SVG 接线图交互设计

## 目标

模拟台和学员台的接线图增加四项一致的交互能力：鼠标悬停设备时展示设备参数，鼠标悬停动态量测值时展示当前值和近期趋势曲线，鼠标点击设备时保持选中高亮，鼠标滚轮围绕指针位置缩放图形。

功能复用现有模型静态数据、实时量测快照和前端量测历史，不增加服务端接口、不增加轮询频率，也不改变学员台前端与服务端之间的既有隔离边界。

## 交互优先级

接线图使用容器级事件委托，不为每个 SVG 元素分别注册监听器。鼠标位置对应的交互目标按以下优先级判断：

1. 带 `mt` 的动态量测占位符显示量测趋势提示。
2. 带 `dev-id`、`dev` 或对应设备标签的元素显示设备参数提示。
3. 接线图空白区域不显示提示。

当模型切换、SVG 变化、页面离开接线图或鼠标移出接线图时，立即隐藏旧提示，禁止残留上一个模型的数据。

## 设备选中状态

- 点击设备本体、设备名称或该设备的动态量测区域时，按 SVG 设备标识选中该设备。
- 同一时刻只允许一个设备处于选中状态；点击另一设备时切换选中。
- 点击接线图空白区域时取消当前选择。
- 选中效果同时作用于具有相同 `dev-id` 的设备本体和名称，以及具有相同 `dev` 的量测区域，使同一设备的图形与数据保持一致高亮。
- 选中状态在实时量测文本更新、小时/日曲线分页切换和滚轮缩放期间保持，不触发模型树筛选或其他页面的设备选择。
- 模型或 SVG 版本变化时清除旧设备选择，禁止将旧模型的设备标识带入新图形。

## 设备参数提示

### 设备识别

沿用 SVG 实时量测绑定建立的设备索引，将 `dev-id/id` 和量测容器的 `dev` 解析为：

```text
{ devId, devType, devName }
```

设备参数从当前模型的 `definitions.model` 和 `devices` 中按设备类型、设备名称匹配。SVG 名称无法匹配当前模型时，只显示 SVG 中可确认的设备名称、类型和标识，不跨设备猜测参数。

### 展示内容

提示框采用紧凑的键值布局，展示：

- 设备名称、设备类型和 `idx`。
- 当前运行状态、开关状态和控制模式。
- 当前设定值。
- Model.e 中除重复标识字段外的静态参数。
- 当前设备可匹配的有效实时量测。

提示框限制最大宽度和最大高度。参数过多时内容区允许竖向滚动，但提示框本身不改变接线图布局。

## 动态量测趋势提示

### 当前值

量测提示显示设备名称、量测类型、当前有符号值、单位和有效状态。当前值继续遵守接线图实时绑定规则：

- 遥测 `measurements.scada` 优先，缺少对应遥测行时回退 `measurements.real`。
- 空值显示 `--`，不补零。
- 不使用 `abs`、`min` 或 `max` 修改实时值。
- SOC 只做标幺值到百分数的 `value * 100` 换算，不裁剪越界结果。

### 小时和日曲线分页

趋势曲线复用现有 `state.measurementTraceHistory`，并在量测提示框中提供两个分页标签：

- `小时曲线`：显示截至当前仿真时刻的最近 1 小时数据，作为默认分页。
- `日曲线`：显示截至当前仿真时刻的最近 24 小时数据。

用户可以直接在提示框内切换分页。切换后保持当前量测和提示位置，不需要重新移动鼠标。当前选择在本次页面会话内保留，切换到另一个动态量测时沿用相同分页。

曲线不再使用固定的 120 点上限。前端根据微型曲线的实际显示宽度自适应采样；数据过密时按时间桶保留每桶的首值、末值、最小值和最大值，既控制绘制开销，也保留尖峰和阶跃特征。

- 模拟台曲线优先使用历史遥测值，缺失时使用历史实时值。
- 学员台使用学员台服务端已经同步到本地历史中的量测值。
- 趋势范围内没有有效点时保留当前值，并显示“当前分页暂无历史曲线”。

提示中的微型曲线显示分页名称、起止仿真时刻、最小值、最大值和最新值。横轴按仿真时刻排列，纵轴根据当前分页的有效数据自动缩放；所有值相同时给纵轴增加最小显示跨度，避免生成无高度曲线。

### 实时更新

提示框 DOM 只创建一次。鼠标移动只更新提示位置；悬停目标变化、分页切换或新快照到达时才重建提示内容和趋势曲线。鼠标从动态值移入提示框时保持提示可见，以便操作小时和日分页；移出动态值与提示框后再隐藏。这样既支持分页操作，也避免高频 `pointermove` 导致重复生成 DOM。

## 滚轮缩放

### 缩放方式

缩放通过修改内联 SVG 的 `viewBox` 实现，不替换 SVG DOM，不破坏实时量测元素及其绑定缓存。

- 初始比例为 `1x`，最大比例为 `8x`。
- 向上滚动放大，向下滚动缩小。
- 使用 SVG 屏幕坐标变换计算指针对应的图形坐标，缩放后该图形坐标尽量保持在鼠标下方。
- 缩放后的 `viewBox` 限制在原始图形边界内，避免图形完全移出可视区域。
- 仅当滚轮事件发生在 SVG 内部时调用 `preventDefault`，页面其他区域保持正常滚动。

模型或 SVG 版本变化时丢弃旧缩放状态，新图形恢复 `1x`。普通实时量测刷新不得重置用户当前缩放比例。

## 组件与缓存

每个接线图容器维护一份弱引用交互状态：

```text
设备索引
量测语义绑定
当前悬停目标
原始和当前 viewBox
Tooltip DOM 引用
事件是否已经初始化
```

SVG 重建时清理与旧 SVG 关联的绑定、悬停和缩放状态。弱引用缓存允许已移除的容器和 SVG 被浏览器回收。

## 样式与可用性

- 设备本体和动态量测值显示可交互鼠标指针。
- 选中设备使用稳定的描边或投影高亮，不能通过改变元素尺寸造成图形跳动。
- Tooltip 使用高对比度浅色背景、细边框和轻阴影，不使用大面积装饰色。
- 动态值提示使用固定尺寸的微型趋势区域，避免内容更新造成弹窗跳动。
- Tooltip 保持在视口范围内，靠近右边或下边时自动翻转到指针另一侧。
- 设备参数提示不接收鼠标事件；量测趋势提示只在分页标签区域接收操作，并使用短暂离开判定避免设备元素与提示框之间发生悬停抖动。

## 错误处理

- SVG 缺少设备语义属性时跳过该元素，不影响其他设备。
- 找不到设备静态参数时展示可确认的基础身份信息。
- 找不到实时值或历史值时展示明确的缺失状态，不抛出页面错误。
- SVG 不提供有效 `viewBox` 时禁用缩放，但保留悬停提示。
- 页面切换和模型切换必须清除可见 Tooltip。

## 测试

1. 测试动态量测目标优先于设备目标。
2. 测试设备索引能够解析 `dev-id/name` 和 `[dev]` 量测容器。
3. 测试点击设备、设备名称或动态量测区域会统一选中对应设备，点击空白取消选择。
4. 测试实时刷新和缩放保留选择，模型或 SVG 切换清除选择。
5. 测试小时分页使用最近 1 小时、日分页使用最近 24 小时，并保持有符号值。
6. 测试宽度自适应采样保留时间桶中的首值、末值、最小值和最大值。
7. 测试 SOC 趋势换算百分比且不裁剪。
8. 测试缩放比例限制、围绕指针缩放和原始边界约束。
9. 测试普通实时刷新不重建 SVG、不重置缩放状态。
10. 测试模型或 SVG 切换后清除旧提示、选择、绑定和缩放状态。
11. 在模拟台和学员台实际页面验证设备提示、设备选择、小时/日曲线分页、滚轮缩放和控制台错误。

## 非目标

- 不新增服务端历史曲线接口或持久化浏览器 Tooltip 历史。
- 不修改用户导入的 SVG 文件。
- 不增加设备拖拽、接线编辑或 SVG 参数编辑功能。
- 不改变实时量测、SOC 或潮流计算逻辑。
