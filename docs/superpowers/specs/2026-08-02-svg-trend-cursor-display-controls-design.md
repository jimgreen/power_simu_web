# SVG 趋势游标与显示控制设计

## 背景与目标

模拟台和学员台已经支持 SVG 接线图实时量测、设备提示、量测趋势、缩放、漫游和设备选择。本次在现有交互基础上补充两组能力：

1. 量测趋势增加纵坐标、刻度、单位和跟随鼠标的最近点游标。
2. SVG 空白处增加显示控制右键菜单，用于控制量测、设备标识和有功流动箭头。

两端采用相同的交互规则和计算规则，但显示偏好必须按模拟台、学员台分别持久化。同一控制台的偏好跨模型共用，刷新页面、切换模型或重启 WEB 服务后继续生效。

本功能只消费现有模型静态数据、实时量测、设备运行状态和前端历史数据，不新增服务端轮询，不修改模型文件，也不改变潮流与控制算法。

## 总体方案

采用 SVG 原生图层方案。趋势坐标轴和游标直接绘制在趋势 SVG 中；设备标识和流动箭头作为接线图 SVG 内部的运行时图层；显示开关通过 SVG 根节点状态类控制。

该方案保证所有新增图元与原接线图使用同一套 `viewBox` 坐标。滚轮缩放、拖拽漫游和双击恢复原始范围时，不需要额外同步 HTML 或 Canvas 覆盖层，也不会出现背景、设备和箭头错位。

## 量测趋势图

### 趋势数据模型

现有小时曲线、日曲线取数和自适应采样规则保持不变。在生成图形前，统一构造趋势图模型：

```text
有效并按仿真时刻升序排列的采样点
横轴起止时刻
纵轴最小值、最大值和显示范围
纵轴刻度值与格式化文本
量测单位
```

空值和非有限值不进入折线与游标索引。SOC 继续只做标幺值到百分数换算，不裁剪越界结果；其他量测保留有符号值，不使用 `abs`、`min` 或 `max` 修改实时数据。

### 纵坐标与单位

趋势 SVG 保持固定外部尺寸，但扩大左侧和底部绘图区边距，为纵坐标和时间标签预留稳定空间。

- 纵轴默认生成 4 个可读刻度，覆盖当前分页的完整数据范围。
- 刻度采用“漂亮数值”步长，避免出现过长小数。
- 所有值相同时，在原值上下增加最小显示跨度，防止折线塌缩成无高度图形。
- 每个纵轴刻度对应一条浅色水平网格线。
- 单位只在纵轴附近显示一次，不重复拼接到每个刻度中。
- 小时曲线与日曲线继续显示完整时间范围，游标时间按当前仿真日期和时刻格式化。

### 最近点游标

趋势图内部增加透明命中区域、竖向游标线、数据点圆标和游标数值框。鼠标进入趋势绘图区后：

1. 将浏览器坐标转换为趋势 SVG 的绘图区坐标。
2. 根据横坐标换算目标仿真时刻。
3. 在升序采样点中使用二分查找选择时间最接近的数据点。
4. 更新游标线、圆标和数值框，显示该点的完整时间、格式化数值和单位。

游标只修改预先创建的 SVG 元素，不重建量测提示框，也不重新生成整条曲线。鼠标离开趋势图后立即隐藏游标。设备或量测提示框出现后仍保持固定位置，游标跟随仅发生在趋势图内部。

新实时快照到达并刷新当前趋势时，如果鼠标仍位于绘图区，使用最新采样点重新计算最近点；否则游标保持隐藏。

## SVG 空白处右键菜单

### 打开条件

接线图容器使用既有事件委托处理 `contextmenu`。只有事件目标不能解析为以下任一语义对象时，才视为 SVG 空白区域并打开自定义菜单：

- 设备本体、设备名称或设备编号。
- 动态量测容器或具体量测文本。
- 流动箭头图层。
- 已有设备提示、量测提示或人工操作弹窗。

SVG 的背景矩形或纯装饰图形可视为空白。右键点击设备或量测时不打开显示菜单，也不改变当前设备选择。

菜单以鼠标位置为锚点，并限制在浏览器可视区域内。选择菜单项、点击菜单外部、按下 `Escape`、切换页面或切换模型时关闭菜单。

### 菜单项目

菜单包含三个二态项目，文字反映点击后将执行的动作：

- `显示量测` / `不显示量测`
- `显示标识` / `不显示标识`
- `显示流动箭头` / `不显示流动箭头`

点击后立即应用到当前 SVG，并持久化对应控制台的偏好。菜单切换不能触发设备选择、画布漫游或双击操作。

## 量测与设备标识图层

### 量测显示

初始化 SVG 时，将所有 `[dev]` 量测组以及可由现有量测绑定识别的独立量测元素标记为运行时量测图层。关闭量测显示时隐藏完整量测内容，包括量测名称、数值和单位；实时数据仍继续绑定和更新，重新显示时无需重新请求数据。

量测显示开关只控制接线图中的量测文字，不影响设备提示框、量测趋势历史采集或其他页面的实时量测。

### 标识显示

“标识”同时包含设备名称和设备编号。

- 现有 `text[id^="label_"][dev-id]` 作为设备名称标识。
- SVG 未提供设备编号文本时，在运行时为对应名称生成较小的设备编号文本，内容取稳定的 `dev-id`，并与名称归入同一标识图层。
- 设备编号的位置相对名称保持固定，不参与设备几何尺寸计算，也不改变原始 `viewBox`。
- 名称与编号一起显示或隐藏。
- 运行时生成的编号不写回导入的 SVG 文件。

模型或 SVG 版本变化时，移除旧运行时编号并针对新图形重建，禁止残留上一个模型的标识。

## 有功流动箭头

### 几何与量测绑定

流动箭头只在能够同时确定“稳定路径几何”和“有效有功量测”的图元上生成，不根据名称猜测功率，也不在没有方向依据的装饰连线上生成。

路径解析按以下优先级进行：

1. 具有设备标识并能解析实际路径的交流、直流支路或零阻抗支路。
2. 具有 `source-dev-id`、`target-dev-id` 的显式连接路径，且能够唯一绑定到相邻的有功设备或支路。
3. 引用 `<symbol>` 的自适应线路 `<use>`，解析其符号内的线路路径并应用与 `<use>` 一致的平移、缩放和 `viewBox` 变换。

如果一个连接存在多个可能的功率来源，或无法确认节点顺序与图形方向，则跳过该连接，不能使用任意设备功率代替。

有功值沿用现有量测绑定优先级，从当前设备的有效 `activePower`/对应有功遥测获取。所有计算保留功率符号，不调用 `abs` 改变方向。

### 方向

正功率按照设备 `node-1 -> node-2` 或路径 `source-dev-id -> target-dev-id` 的定义方向流动，负功率按照相反方向流动。方向变化时更新箭头运动方向，不重新创建整张 SVG。

箭头使用 SVG 原生运动图元或等价的 SVG 内部动画，运动速度保持稳定。功率大小只影响箭头尺寸，不用速度放大瞬时波动。

### 尺寸

箭头显示尺寸限制在 `6px` 到 `16px`。尺寸采用平方根比例：

```text
ratio = clamp(abs(P) / referencePower, 0, 1)
size = 6 + 10 * sqrt(ratio)
```

`referencePower` 优先取设备有效的额定容量、额定功率或有功上限，并先换算到与实时有功一致的单位。静态参数缺失时，使用当前模型会话内同类有效量测的峰值保持量作为参考；模型切换时重置该回退参考值。

该换算只用于箭头视觉尺寸，不修改或覆盖页面展示的有功实时值。

### 隐藏条件

以下任一条件满足时，该图元不显示流动箭头：

- 显示偏好关闭流动箭头。
- 设备退运、不可用或处于死岛。
- 路径任一必需端点处于死岛，导致流向语义失效。
- 没有有效有功量测，量测值不是有限数。
- `abs(P)` 不超过参考功率的 `0.1%`；没有参考功率时，以当前量测显示精度的一半作为近零阈值，例如显示 3 位小数时阈值为 `0.0005` 个当前单位。

实时量测更新时只修改已有箭头的方向、尺寸、可见性和绑定值。模型或 SVG 版本变化时重建箭头索引和运行时图层。普通实时刷新不得重建原始 SVG，也不得重置缩放、漫游或设备选择状态。

## 显示偏好持久化

### 存储范围

显示偏好属于浏览器中的控制台视图设置，不写入模型文件，也不通过模拟台与学员台服务端互相同步。

模拟台和学员台分别使用以下版本化存储键：

```text
simulator.svgDisplayPreferences.v1
trainee.svgDisplayPreferences.v1
```

存储结构为：

```json
{
  "measurements": true,
  "labels": true,
  "flowArrows": true
}
```

三个项目默认均为 `true`。同一控制台内所有模型读取同一份配置；切换模型不改变偏好。浏览器刷新、重新打开页面或 WEB 服务重启后，从 `localStorage` 恢复。

同一控制台的多个页面通过 `storage` 事件同步偏好。模拟台与学员台即使在同一浏览器中打开，也因为键名和服务端来源不同而互不影响。

若浏览器禁用存储、配额异常或存储内容损坏，页面使用默认值并继续运行；显示操作在当前页面会话内仍可生效，不能因此阻断 SVG 加载。

## 生命周期与性能

每个接线图交互状态增加以下缓存：

```text
当前显示偏好
右键菜单 DOM 引用
名称与编号标识索引
箭头路径、功率绑定和参考功率索引
当前趋势图游标状态
```

- 继续使用容器级事件委托，不给每个设备和量测注册独立鼠标监听器。
- 箭头动画由 SVG/CSS 动画驱动，不为每个箭头启动独立 JavaScript 定时器。
- 实时更新批量写入箭头属性，并在接线图不可见时暂停视觉更新；历史量测采集保持正常。
- 页面离开接线图、模型切换或 SVG 重建时，关闭菜单和提示框，清理旧运行时图层与绑定。
- 缩放和漫游仅修改原 SVG 的 `viewBox`，新增标识与箭头随图形同步变化。

## 错误处理

- 趋势没有有效点时显示空态，不显示游标，但仍保留纵轴单位。
- 单位缺失时不显示单位文字，不使用错误的默认单位猜测。
- 无法计算漂亮刻度时回退到数据最小值、中点和最大值。
- 无法解析线路路径或功率方向时跳过该箭头，不影响其他图元。
- 单个运行时标识或箭头创建失败时记录前端诊断信息，继续更新其他设备。
- 损坏的持久化配置按字段校验，非法字段回退默认值。

## 测试与验收

### 自动化测试

1. 测试纵轴显示单位、漂亮刻度和水平网格线。
2. 测试全等数据能够生成非零纵轴范围。
3. 测试最近点二分选择，包括区间两端和等距离边界。
4. 测试游标显示对应时间、有符号值和单位，离开曲线后隐藏。
5. 测试模拟台与学员台使用不同持久化键，默认值均为全部显示。
6. 测试损坏配置回退默认值，同一控制台的模型切换保持设置。
7. 测试自定义菜单仅在 SVG 语义空白处打开。
8. 测试关闭量测不会停止实时绑定和趋势历史采集。
9. 测试设备名称和运行时设备编号同时显示、同时隐藏。
10. 测试有功正负值产生相反箭头方向。
11. 测试平方根尺寸计算和 `6px`、`16px` 上下限。
12. 测试停运、死岛、缺失量测和近零功率隐藏箭头。
13. 测试实时更新不重建 SVG，并保持缩放、漫游和设备选择。
14. 测试模型切换清理旧菜单、编号、箭头、绑定和游标状态。

### 浏览器验收

在模拟台和学员台分别验证：

- 小时、日趋势分页均有纵轴、刻度、单位和最近点游标。
- 游标跟随鼠标，外层提示框不跟随移动，离开趋势后游标消失。
- 右键菜单只在空白区域出现，靠近视口边缘时不会溢出。
- 三项显示开关立即生效，刷新、切换模型和重启 WEB 后保持。
- 同一控制台多个页面同步，模拟台与学员台互不影响。
- 箭头方向匹配实时有功符号，尺寸随有功绝对值变化。
- 停运、死岛和近零功率设备不显示箭头。
- 放大、缩小、漫游和双击恢复后，标识与箭头仍与设备路径对齐。
- 桌面和窄屏页面无横向溢出，浏览器控制台无新增错误或警告。

## 非目标

- 不修改用户导入的 SVG 文件或自动回写设备编号。
- 不新增服务端显示偏好接口，也不跨浏览器同步偏好。
- 不根据前端图形重新计算潮流、拓扑或设备功率。
- 不为缺少明确路径或有功方向的数据强行生成流动箭头。
- 不改变小时曲线、日曲线的历史采集周期和数据保留策略。
