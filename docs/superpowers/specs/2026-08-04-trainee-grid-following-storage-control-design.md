# 学员台新能源控制拓扑分侧与储能扩展设计

## 背景

学员台新能源实时控制当前按模型参数块和底层设备类型识别风电、光伏与储能：`ACWindGen` 被视为交流风电，`DCPVGen` 被视为直流光伏，`DCStorageGen` 被统一视为直流平衡储能。这种做法不能表达以下实际拓扑：

- 一个 `ACGenerator` 形式的风机经过整流或其他变流器接入直流母线。
- 一个 `DCGenerator` 形式的光伏或储能经过 DCAC 变流器接入交流母线。
- 同一种新能源既可能交流并网，也可能直流并网。
- 储能除了交流/直流并网侧，还需要区分跟网储能与平衡储能。
- 直流侧风光、跟网储能和平衡储能只有通过与其处于同一有效直流电气岛的 ACDC 变流器，才能向交流电网提供功率。

因此，设备名称、参数块名称以及底层 `ACGenerator/DCGenerator` 类型都不能直接决定最终并网侧。并网侧必须由设备端到真实母线的电气拓扑推导。

本次设计同时覆盖：

- 风电、光伏按实际拓扑区分交流并网与直流并网。
- 储能按“并网侧 × 控制角色”区分交流跟网、直流跟网、交流平衡、直流平衡四类。
- 直流资源通过 ACDC 变流器向交流电网送电，并按直流电气岛隔离传输容量。
- 交流侧与直流侧的新能源恢复、储能充放电、平衡储能保护和柴油下限控制保持能量守恒，避免重复计算。

## 已确认的原则

### 功率符号

跟网储能独立有功设定点统一采用：

```text
p_set > 0：放电，向所在电网注入有功功率
p_set < 0：充电，从所在电网吸收有功功率
p_set = 0：不充不放
```

ACDC 继续沿用现有符号：

```text
p_ac_set < 0：直流侧向交流侧送电
p_ac_set > 0：交流侧向直流侧倒送
```

自动控制禁止 `p_ac_set > 0`，即禁止交流电网或柴油发电机通过 ACDC 给直流侧充电。

### 数据与约束来源

- SOC、能量容量、效率、最大充电功率、最大放电功率以及 SOC 运行上下限来自 `model.e`。
- 实时有功和 SOC 保持原始有符号值，不对量测执行 `abs`、`max` 或 `min` 修饰。
- SOC 积分结果不强制限制在 0% 至 100%，异常值要通过控制策略、指标和日志暴露。
- 环境变量默认不参与控制决策；风光恢复使用当前值、额定容量和配置步长。
- 每个仿真时刻最多计算并下发一轮自动控制策略。
- “启动接收”是新能源实时控制运行的硬前置条件。
- 自动指令使用现有可配置有效期，默认 120 分钟，并按现有规则覆盖同点人工指令。

## 方案选择

### 名称或参数块分类

根据设备名中的“交流/直流”、`AC/DC` 前缀，或根据 `ACWindGen/DCPVGen` 等参数块名称分类，实现简单但会在设备经过变流器接入另一种母线时产生错误，不采用。

### 底层设备类型分类

根据资源最终引用 `ACGenerator` 还是 `DCGenerator` 分类，仍然只能说明设备端电气形式，不能说明经过专用变流器后的最终并网母线，不采用。

### 真实母线拓扑追踪

从资源设备端节点出发，收缩开关、刀闸、断路器和零阻抗支路，沿线路、变压器与变流器追踪到最近的 `ACRealBs` 或 `DCRealBs`。真实母线类型决定结构并网侧，运行状态图决定当前是否接入以及可用传输路径。该方案不依赖名称，能够正确处理跨域变流器和多直流岛，采用此方案。

## 资源识别与并网侧分离

参数块只用于识别资源技术类型及读取技术参数，不用于决定最终并网侧。

### 风电

支持以下技术参数来源：

- `ACWindGen -> ACGenerator`
- `DCWindGen -> DCGenerator`
- 兼容旧模型的 `wind_generator`

无论参数块或底层发电机类型是什么，最终都由拓扑解析得到：

```text
technology=wind + connectionSide=AC -> 交流并网风电
technology=wind + connectionSide=DC -> 直流并网风电
```

### 光伏

支持以下技术参数来源：

- `ACPVGen -> ACGenerator`
- `DCPVGen -> DCGenerator`
- 兼容旧模型的 `pv_generator`

最终分类为：

```text
technology=pv + connectionSide=AC -> 交流并网光伏
technology=pv + connectionSide=DC -> 直流并网光伏
```

### 储能

支持以下技术参数来源：

- `ACStorageGen -> ACGenerator`
- `DCStorageGen -> DCGenerator`
- 兼容旧模型的 `estorage`

并网侧由拓扑解析；控制角色独立判断：

```text
connectionSide=AC + role=grid_following -> 交流跟网储能
connectionSide=DC + role=grid_following -> 直流跟网储能
connectionSide=AC + role=balance       -> 交流平衡储能
connectionSide=DC + role=balance       -> 直流平衡储能
```

跟网储能必须同时满足：

1. 底层设备处于有功可调的 P/PQ 类模式。
2. 控制定义存在该设备的有效 `p_set` 遥调点。
3. 实时 SOC、当前有功和储能边界有效。

平衡储能由 SLACK、V/F、电压平衡等参考控制模式识别，其有功是潮流平衡结果，不直接下发 `p_set`。模式既不属于跟网也不属于平衡，或模型引用不完整时，标记为 `uncontrolled`，不能为了凑分类而猜测角色。

## 拓扑解析器

新增独立的资源拓扑解析单元。输入为同一快照中的模型设备、运行状态、开关状态和死岛状态；输出为每个资源的结构并网侧、实时接入状态、路径和传输组。

### 图节点与真实母线锚点

电气节点使用带域标识的键，避免 AC、DC 节点编号碰撞：

```text
("AC", ACNode.idx)
("DC", DCNode.idx)
```

真实母线锚点为：

```text
ACRealBs.node -> AC 母线锚点
DCRealBs.node -> DC 母线锚点
```

只有 `ACRealBs/DCRealBs` 决定最终并网侧，普通 `ACNode/DCNode` 只是拓扑节点。

### 同域连接

交流域连接包括：

- `ACBranch`
- `ACTransformer`
- `ACZeroBranch`
- `ACSwitch`
- `ACBreak`

直流域连接包括：

- `DCBranch`
- `DCZeroBranch`
- `DCSwitch`
- `DCBreak`

模型中出现其他具有明确同域双端节点字段的线路或刀闸类型时，按设备映射表显式加入，不使用名称模糊匹配。

### 变流器连接

- `ACACConverter` 连接两个交流节点。
- `DCDCConverter` 连接两个直流节点。
- `DCACConverter` 连接一个交流节点和一个直流节点，并在路径中改变电气域。

资源设备本身不是图边，只提供起始端节点。负荷、发电机、储能和其他资源不能作为另一台设备的穿越路径。

### 开关与刀闸收缩

`ACSwitch`、`ACBreak`、`ACZeroBranch` 及对应直流设备在结构图中作为零代价连接收缩。这样，设备与真实母线之间即使存在多级开关、刀闸或零阻抗支路，也不会被错误识别为不同并网侧。

结构分类和实时运行分开计算：

- 结构图保留模型定义的物理连接，用于给设备稳定地确定交流/直流并网侧。
- 运行图只保留在线线路、在线变流器以及处于闭合状态的开关、刀闸和断路器。
- 开关断开后，设备保留结构并网侧，但 `activelyConnected=false`，不参与自动控制。
- 设备或路径处于死岛时，实时路径无效；恢复后下一周期自动重新参与。

### 最近真实母线规则

为避免穿过主网联络变流器后所有设备都同时到达 AC、DC 母线，路径按以下优先级比较：

1. 转换电气域次数更少的路径优先，零次变流优先于经过变流器。
2. 变流次数相同时，非开关电气设备跳数更少的路径优先。
3. 开关、刀闸、断路器和零阻抗支路已被收缩，不增加距离。
4. 到达首个真实母线锚点后停止该路径继续向外扩展。

因此：

- 底层为 `ACGenerator` 的风机，若只能通过 DCAC 到达 `DCRealBs`，仍判为直流并网风电。
- 底层为 `DCGenerator` 的光伏，若只能通过 DCAC 到达 `ACRealBs`，仍判为交流并网光伏。
- 资源无需经过变流器即可到达交流母线时，优先判为交流并网；直流侧同理。

### 歧义与未解析

- 没有任何真实母线可达：`connectionSide=UNRESOLVED`。
- 最优路径同时到达 AC、DC 真实母线：`connectionSide=AMBIGUOUS`。
- 模型引用不存在、节点字段无效或变流器端子不完整：`connectionSide=INVALID`。

这些资源继续显示在模型诊断信息中，但不进入自动策略，不允许根据设备名、参数块前缀或底层类型兜底猜测。

### 解析结果

每台资源至少得到：

```text
technology               wind / pv / storage
resourceDevType
resourceDevName
connectionSide           AC / DC / UNRESOLVED / AMBIGUOUS / INVALID
activelyConnected
structuralPath
activePath
converterPath
busbarType
busbarName
busbarNode
gridComponentId
dcTransferGroupId
topologyStatusLabel
```

## 直流传输组与 ACDC

### 传输组边界

运行图中，每个收缩后的存活直流连通分量形成一个 `dcTransferGroupId`。组内包含：

- 该直流岛的直流并网风电与光伏。
- 该直流岛的直流跟网储能和直流平衡储能。
- 该直流岛的直流负荷及其他本地功率消耗。
- DC 端接入该岛、AC 端接入存活交流电网的 ACDC 变流器。

一个直流岛只能使用本组 ACDC 的容量、实时功率和控制步长，不能借用其他直流岛、断开路径或死岛 ACDC 的能力。

### 方向

自动策略只允许：

```text
直流资源 -> ACDC -> 交流电网
```

不允许：

```text
交流新能源/柴油 -> ACDC -> 直流储能
```

直流侧储能充电必须来自本组直流风电、直流光伏或其他被明确识别的直流新能源富余。

### 直流功率预算

每个传输组分别计算：

```text
DC新能源当前值
DC新能源候选增量
DC本地负荷
DC跟网储能当前值与目标增量
DC平衡储能当前值与可充/可放边界
ACDC当前DC->AC送出
ACDC额定容量、方向裕度和本轮步长
```

能够新增送入交流侧的直流新能源功率为：

```text
min(
  直流新能源可恢复量,
  扣除本地负荷和本地储能充电后的直流净增量,
  本组 ACDC 的 DC->AC 剩余容量,
  本组 ACDC 本轮允许增加的送出功率,
  交流侧柴油下调允许量
)
```

新能源 `p_set` 与 ACDC `p_ac_set` 分别生成独立命令，不能相加后写入同一个设备，但最终校核必须保证二者的配对增量一致。无法通过 ACDC 送出的直流新能源增量只能在本地被储能或负荷吸收，否则不能恢复。

## 四类储能控制语义

### 交流跟网储能

- 使用自身 `p_set` 直接控制。
- 柴发高于下限加死区时，优先按步长增加放电。
- 柴发位于下限死区时保持，不继续增加放电。
- 柴发低于下限时先减少现有放电。
- 充电只能吸收交流侧新能源富余或已经通过 ACDC 送入交流侧的直流新能源富余。
- SOC 达到上限禁止充电，达到下限禁止放电。

### 直流跟网储能

- 使用自身 `p_set` 直接控制。
- 用于降低交流侧柴发时，其新增放电必须与本组 ACDC 新增送出配对，并受本组传输能力限制。
- 充电优先吸收本组直流新能源富余，不允许 ACDC 倒送充电。
- SOC 达到上限禁止充电，达到下限禁止放电。

### 交流平衡储能

- 直接承担交流电网的功率平衡，其有功由潮流决定，不直接下发 `p_set`。
- 其 SOC 和充放电功率必须独立统计，不能与直流平衡储能平均后控制。
- SOC 偏低且正在放电时，通过增加交流风光、交流跟网储能放电或可用 ACDC 送出来降低其放电。
- SOC 偏高且正在充电时，优先由交流跟网储能吸收新能源富余；无吸收能力时逐步降低交流侧新能源或限制 ACDC 送出。

### 直流平衡储能

- 直接承担所在直流岛的功率平衡，其有功由潮流决定，不直接下发 `p_set`。
- 其功率要通过同组 ACDC 才能作用于交流电网。
- ACDC 状态机只能读取和调节其所属直流传输组中的直流平衡储能，不能把交流平衡储能纳入 ACDC 储能功率或 SOC。
- SOC 偏低且正在放电时，减少 ACDC 送出、恢复本组直流新能源或增加本组直流跟网储能放电。
- SOC 偏高且正在充电时，增加 ACDC 送出；若受柴油下限或 ACDC 容量约束，则降低本组直流新能源。

## 控制请求与分配

### 柴发下调

当在线柴发总功率高于下限加死区时，形成交流侧供电增量请求。执行顺序为：

1. 现有 ACDC 平衡策略生成独立候选目标。
2. 交流跟网储能按步长增加放电。
3. 各直流传输组中的直流跟网储能，在本组 ACDC 有剩余送出能力时增加放电并配对增加 ACDC 送出。
4. 交流风光恢复。
5. 直流风光仅在本组 ACDC 能同步增加送出时恢复。

统一校核根据 ACDC 候选已经产生的柴油预测效果计算剩余偏差，后续执行器只承担剩余量，不能每条策略都对同一柴油偏差全额动作。

### 柴发下限死区

- 不继续增加交流跟网储能、直流跟网储能或 ACDC 向交流侧的送出。
- 允许为 SOC 硬约束而减少放电、减少送出或降低新能源。
- 正常区域内保持当前目标，避免跨越边界后反向调整造成振荡。

### 柴发低于下限

- 先减少交流跟网储能放电。
- 再减少各直流传输组的 ACDC 送出和直流跟网储能配对放电。
- 不因低 SOC 主动形成柴油给储能充电的策略。
- 只有已经存在的同侧新能源富余可以形成储能充电目标。

### 新能源恢复与充电

交流侧新能源恢复必须有以下至少一个去向：

- 交流侧负荷及允许的柴油下调空间。
- 交流跟网储能充电空间。
- 交流平衡储能允许的充电空间。

直流侧新能源恢复必须有以下至少一个去向：

- 同组直流负荷。
- 同组直流跟网储能或直流平衡储能的充电空间。
- 同组 ACDC 可增加的 DC->AC 送出，并且交流侧存在可接受功率的负荷、柴油下调空间或交流储能充电空间。

没有可验证去向的新能源增量不得下发。储能充电预算不得跨侧凭空转移。

### 同类多设备分配

同一侧、同一角色或同一传输组内的多台设备按本轮可用裕度比例分配：

```text
设备分配量 = 组级请求量 * 设备可用裕度 / 组内可用裕度总和
```

分配后逐台执行功率、SOC、能量和步长裁剪，剩余量只在同一合法分配组内重新分配。

## SOC 与功率边界

- `SOC >= soc_upper_limit`：禁止继续增加充电；允许减少充电或增加放电。
- `SOC <= soc_lower_limit`：禁止继续增加放电；允许减少放电；充电仍必须有同侧新能源富余。
- 上限附近按现有充电线性降额曲线收缩允许充电功率。
- 下限附近按现有放电线性降额曲线收缩允许放电功率。
- 能量裕度按控制周期折算，候选目标不能使预测 SOC 在单周期内越过 `model.e` 运行上下限。
- SOC 无有效实时量测时，只展示静态参考值，不允许设备参与自动控制。
- 交流和直流平衡储能分别计算能量加权 SOC，不进行跨侧算术平均。

## 统一最终校核

状态机只生成候选目标。所有候选必须按以下顺序统一校核：

1. 资源技术参数引用有效。
2. 结构并网侧唯一可解析。
3. 当前运行拓扑存在有效接入路径，设备不处于死岛。
4. 控制模式和遥调点有效。
5. 实时有功、SOC 和边界数据有效。
6. 单机功率上下限、SOC 线性降额和单周期能量裕度。
7. 单周期控制步长与控制方向。
8. 直流资源属于明确的 `dcTransferGroupId`。
9. 同组 ACDC 在线、方向正确且具有剩余容量和步长。
10. 同侧新能源富余与储能充电量满足功率守恒。
11. ACDC、新能源和跟网储能组合动作后的柴油预测边界。

只要本轮动作使柴油下限偏差缩小，且没有触发其他硬约束，就允许下发；不要求一个周期完全达标。若组合动作将原本合格的柴油出力推到下限以下，按剩余允许修正量裁剪后续执行器。

ACDC、风光和跟网储能各自收到自己的目标，不把多个策略数值相加后写入某一设备。

## 指令生成与仲裁

跟网储能命令：

```json
{
  "dev_type": "ACGenerator 或 DCGenerator",
  "dev_name": "设备名称",
  "set_type": "p_set",
  "set_value": "有符号目标功率"
}
```

风光继续使用其模型定义的有功遥调点。ACDC 使用自己的 `p_ac_set`。平衡储能不生成直接 `p_set`。

- 开环模式只输出候选值、校核结果和日志。
- 闭环模式才写入自动遥调指令。
- 目标与当前值之差小于数值容差时不重复生成指令，但保留“保持”策略行。
- 单台设备无控制点只禁用该设备，不阻断其他合法策略。
- 同一仿真时刻的重复页面请求不得造成重复下发。

## 页面展示

新能源策略页按拓扑解析结果展示：

```text
交流风电 | 直流风电 | 交流光伏 | 直流光伏
交流跟网储能 | 直流跟网储能
交流平衡储能 | 直流平衡储能
柴发 | ACDC变流
```

每个新能源或储能表格增加：

- 结构并网侧。
- 当前接入状态。
- 接入母线名称。
- 传输组编号，交流直连设备显示 `--`。
- 经过的变流器或“直接接入”。
- 拓扑异常原因。

跟网储能继续显示遥调点、当前功率、目标功率、SOC、SOC 上下限以及允许充放电功率。平衡储能显示当前功率、SOC、边界和间接调节设备，不显示可执行 `p_set`。

综合指标分别统计：

- 交流风电、直流风电当前与目标。
- 交流光伏、直流光伏当前与目标。
- 四类储能的当前功率、目标功率和能量加权 SOC。
- 每个直流传输组的新能源、储能、ACDC 当前/目标及受限量。
- 实际可供交流负荷使用的直流绿电功率。

只有通过有效 ACDC 路径实际送入交流侧的直流新能源功率，才计入“向交流负荷供电的直流绿电”；不能直接把全部直流风光出力计入。

## 日志

每轮日志至少包含：

- 每台资源的拓扑并网侧、当前接入状态和母线。
- 无法解析、路径断开或拓扑歧义的原因。
- 每个直流传输组的功率预算和 ACDC 传输边界。
- 交流/直流风光恢复量与实际去向。
- 四类储能的 SOC 区域、允许裕度和候选目标。
- ACDC 候选已经承担的柴油修正量。
- 因 SOC、步长、能量、拓扑、ACDC 容量或柴油边界被裁剪的功率。
- 每台设备开环未下发、闭环已下发或保持不重复下发的结果。

## 代码边界

### 新增拓扑解析单元

新增聚焦的资源拓扑模块，负责：

- 从快照模型建立结构图和运行图。
- 收缩开关、刀闸、断路器与零阻抗支路。
- 解析每台风光和储能的并网侧、母线、路径及异常。
- 建立运行中的直流传输组及关联 ACDC 列表。

控制器只消费解析结果，不在状态机内部重复实现图搜索。

### 学员台后台

- `simu/renewable_control.py`：读取拓扑分类，标准化风光和四类储能，生成分侧候选、分组分配、统一校核、指标、日志与命令。
- `simu/service.py`：快照 `device_parameters` 暴露 `ACWindGen`、`DCWindGen`、`ACPVGen`、`DCPVGen`、`ACStorageGen`、`DCStorageGen`。
- `simu/server.py`：保持模型级单例控制器、接收前置条件、每仿真时刻一次和自动指令有效期。

### 模拟台运行数据

- `simu_loop.py`：储能定义、功率约束、实际功率快照与 SOC 积分同时支持 AC/DC 底层设备及四种拓扑/角色组合。
- `simu/server.py`：自动生成的 `StorageSoc`、SOC 量测和控制定义保留底层 `dev_type + name`，不再只生成 DC 储能。
- 不新增第二套 SOC 文件，不暂停仿真线程，不生成额外 runtime 模型文件。

### 学员台页面

- `simu/web/trainee/index.html`：增加拓扑分侧策略标签和拓扑列。
- `simu/web/trainee/app.js`：按后台 `category/connectionSide/role` 渲染，不在前端根据名称重新分类。
- 页面只展示后台结论，前端不重新实现电气拓扑算法。

## 异常处理

- 资源参数引用不存在：标记模型引用无效，不参与控制。
- 找不到真实母线：标记未解析，不根据名称兜底。
- 最优路径同时到达 AC/DC 母线：标记拓扑歧义，不参与控制。
- 结构并网侧已知但实时路径断开：保留分类，标记当前断开，不参与控制。
- ACDC 全部离线或无有效 AC 端：对应直流传输组不能向交流侧送电。
- 直流新能源没有本地吸收空间且不能通过 ACDC 送出：保持或降低，不恢复。
- SOC、有功或容量无效：只禁用对应设备。
- 快照在计算期间失去接收状态：丢弃整轮结果，不产生部分指令。
- 任一候选不是有限数：丢弃该设备候选并记录错误，其他设备继续处理。

## 测试设计

所有生产修改按测试驱动方式实施，先写失败测试并确认失败原因。

### 拓扑解析单元测试

1. 名称包含“直流”的资源直接接入交流母线时仍判为 AC。
2. 名称包含“交流”的资源直接接入直流母线时仍判为 DC。
3. `ACGenerator` 风机经过 DCAC 只能到达 `DCRealBs` 时判为 DC。
4. `DCGenerator` 光伏经过 DCAC 只能到达 `ACRealBs` 时判为 AC。
5. 多级闭合开关、刀闸、断路器和零阻抗支路被正确收缩。
6. 开关断开后结构侧不变，但 `activelyConnected=false`。
7. 经过零次变流可达的真实母线优先于经过变流器可达的母线。
8. 同优先级同时到达 AC/DC 母线时返回 `AMBIGUOUS`。
9. 无真实母线可达时返回 `UNRESOLVED`。
10. 无效节点和变流器端子返回 `INVALID`，不抛出未处理异常。

### 直流传输组测试

1. 两个断开的直流岛生成两个不同传输组。
2. 每个组只包含 DC 端实际接入该岛的 ACDC。
3. 开放直流开关后资源与原 ACDC 不再处于同一活动传输组。
4. ACDC AC 端处于死岛时不能提供送出能力。
5. 一个组的剩余容量不能分配给另一个组。
6. ACDC 倒送方向始终被禁止。

### 资源分类测试

1. 风电和光伏技术类型来自参数关系，并网侧来自拓扑。
2. AC/DC 参数块前缀与最终并网侧相反时，仍采用拓扑结果。
3. P/PQ 且有 `p_set` 的储能归类为跟网储能。
4. SLACK/V/F 参考储能归类为平衡储能且不生成直接指令。
5. 交流与直流平衡储能分别统计，不跨侧平均 SOC。
6. 模型中不存在的设备不会出现在策略表。

### 控制策略测试

1. 柴发高于下限死区时，交流跟网储能先按步长增加放电。
2. 直流跟网储能增加放电时，同组 ACDC 产生匹配的 DC->AC 送出增量。
3. ACDC 无容量时，直流跟网储能不能被当作交流侧柴油修正资源。
4. 交流风光恢复直接计入交流侧功率效果。
5. 直流风光只有在本地有去向或 ACDC 能配对送出时才恢复。
6. 柴发处于下限死区时，不继续增加储能或 ACDC 送出。
7. 柴发低于下限时，先减少储能放电和 ACDC 送出，不形成柴油充电策略。
8. 交流新能源富余不能经 ACDC 给直流储能充电。
9. 直流新能源富余优先在同组直流储能吸收，剩余才通过 ACDC 送入交流侧。
10. ACDC、风光和储能组合动作只承担一次剩余柴油偏差。

### 平衡储能测试

1. 交流平衡储能无直接 `p_set` 指令。
2. 直流平衡储能无直接 `p_set` 指令，其交流侧功率效果只来自同组 ACDC。
3. 交流平衡储能 SOC 偏低时优先增加交流侧供电资源，减少其放电。
4. 直流平衡储能 SOC 偏低时减少同组 ACDC 送出或增加本组直流新能源。
5. 直流平衡储能 SOC 偏高时增加 ACDC 送出，受限后再降低本组直流新能源。
6. SOC 上下限、线性降额和单周期能量裕度分别作用于每台储能。

### 模拟台 SOC 测试

1. AC/ DC 跟网和平衡储能均使用实际潮流终端功率积分 SOC。
2. 放电使 SOC 下降，充电使 SOC 上升。
3. SOC 结果不裁剪到 0% 至 100%。
4. 设备退运、路径断开或死岛后实际功率归零，不使用陈旧功率继续积分。
5. 自动生成的 `StorageSoc` 和 SOC 量测保留正确的底层 `dev_type`。

### 指令与页面测试

1. 跟网储能生成自身 `p_set`，平衡储能不生成。
2. 直流资源与 ACDC 分别生成独立目标，不做数值相加或复制。
3. 页面按后台拓扑分类显示十个策略标签。
4. 页面显示母线、连接状态、路径和传输组。
5. 前端源码不包含基于名称、参数块前缀或 `ACGenerator/DCGenerator` 的并网侧猜测。
6. 综合指标只把实际通过 ACDC 送入交流侧的直流新能源计入交流供电。
7. 开环、闭环、接收前置条件、每时刻一次和 120 分钟自动指令有效期继续成立。

## 验收标准

- 任意风电、光伏或储能的交流/直流并网分类都能由其到真实母线的拓扑路径解释。
- 修改设备名称不会改变并网侧分类。
- 底层发电机类型与最终并网母线相反时仍能正确分类。
- 开关分合不会让设备在结构分类标签间跳动，但会正确改变当前接入状态和控制资格。
- 不同直流岛只使用各自 ACDC 的容量和方向裕度。
- 直流风光和直流储能只有通过有效 ACDC 路径才能为交流负荷供电或压低柴发。
- ACDC 不发生交流向直流倒送，不使用柴油给直流储能充电。
- 交流/直流跟网储能各自得到合理的直接 `p_set`；交流/直流平衡储能均不收到直接功率指令。
- 交流与直流平衡储能的 SOC、功率和保护策略分别计算。
- 风光、储能和 ACDC 的组合目标满足功率守恒、设备边界、SOC、步长、拓扑和柴油边界。
- 模拟台与学员台对资源分类、当前功率、SOC、目标、传输组和指令结果一致。

## 非目标

- 不根据名称修复或猜测错误模型。
- 不自动向 `model.e` 添加风电、光伏、储能或变流器设备。
- 不改变潮流内核已有的设备功率符号。
- 不允许 ACDC 自动倒送。
- 不增加柴油主动给储能充电的应急模式。
- 不把普通 `ACNode/DCNode` 当作最终并网母线锚点。
- 不在前端重复实现拓扑解析。
- 不新增第二个新能源控制线程、页面级算法实例或独立指令仲裁器。
