# 学员台新能源控制增加交流/直流跟网储能设计

## 背景

学员台新能源实时控制目前把 `DCStorageGen` 统一作为“储能平衡源”展示，只通过 ACDC 变流器间接影响储能功率，不会对储能本体生成 `p_set` 遥调指令。该模型能够覆盖由 V/SLACK 电压源支撑的直流平衡储能，但无法覆盖交流侧或直流侧以 P/PQ 模式并网、具有独立有功设定点的跟网储能。

本次扩展要同时支持：

- 交流侧跟网储能：由 `ACStorageGen` 引用 `ACGenerator`，通过 `ACGenerator.<name>.p_set` 控制。
- 直流侧跟网储能：由 `DCStorageGen` 引用 `DCGenerator`，通过 `DCGenerator.<name>.p_set` 控制。
- 现有直流平衡储能：继续由 ACDC 变流器间接调节，不向储能本体下发功率指令。

统一功率符号为：

```text
p_set > 0：储能放电，向所在电网注入有功功率
p_set < 0：储能充电，从所在电网吸收有功功率
p_set = 0：不充不放
```

储能 SOC、能量容量、充放电功率边界、效率及 SOC 运行上下限均来自 `model.e`。环境变量不参与储能控制决策。

## 目标

- 学员台后台识别交流侧、直流侧跟网储能，并持续计算每台储能的合理目标功率。
- 闭环模式下生成并下发独立的储能 `p_set` 自动遥调指令；开环模式只输出策略和日志。
- 储能放电服务于压低柴发出力，储能充电只吸收新能源富余，不主动抬高柴发出力给储能充电。
- SOC 上限禁止继续充电，SOC 下限禁止继续放电；接近边界时继续采用现有线性充放电降额曲线。
- 交流储能与直流储能按已确认的侧别优先级和可用裕度分配控制量。
- 保留现有 ACDC 变流器策略，但不把 ACDC 目标与储能目标相加后作为某一条指令；每个设备只接收自己的目标值。
- 模拟台生成的模型、量测及运行快照能够向学员台完整提供交流/直流储能定义和实时 SOC。
- 多个 WEB 页面访问同一个后台控制器时，继续共享同一套状态、策略、日志和下发节流规则。

## 方案比较

### 方案一：把所有 `DCStorageGen` 都改为直接可控

实现量最小，但会把现有平衡储能误判为跟网储能，产生与 ACDC 电压/平衡控制冲突的 `p_set` 指令。该方案无法支持交流侧储能，也会破坏现有模型兼容性，不采用。

### 方案二：在储能参数块中新增强制角色字段

例如增加 `control_role=grid_following/balance`。角色最明确，但要求所有历史模型迁移；旧模型没有该字段时仍需推断，导入导出和模型编辑也要同步升级。当前需求没有必要引入强制迁移，不作为首选。

### 方案三：按设备类型、控制模式和控制点联合判定

新增与 `DCStorageGen` 对称的 `ACStorageGen` 参数块。储能只有同时满足以下条件才属于直接可控跟网储能：

1. 引用的底层发电设备存在且在线。
2. 交流储能采用 P/PQ 类有功可调模式，直流储能采用 P 类有功可调模式。
3. 控制定義中存在该设备的有效 `p_set` 遥调点。
4. 实时 SOC 有效，充放电功率和能量边界可解析。

V/SLACK 模式、缺少 `p_set` 点或被现有平衡链路使用的储能继续作为平衡储能，只展示、不直控。该方案向后兼容，且不会凭空创建模型中不存在的设备，采用此方案。

## 模型与数据定义

### 储能参数块

保留现有 `DCStorageGen`，并支持同构的 `ACStorageGen`：

```text
<ACStorageGen>
@ idx  idx_acgenerator  storage_technology  battery_rack_count  energy_capacity  charge_discharge_efficiency  max_charge_power  max_discharge_power  state_of_charge  soc_upper_limit  soc_lower_limit
...
</ACStorageGen>
```

`ACStorageGen.idx_acgenerator` 引用 `ACGenerator.idx`；`DCStorageGen.idx_dcgenerator` 引用 `DCGenerator.idx`。不在控制器中合成任何储能设备，模型中没有相应定义时，对应页面为空。

### 实时 SOC

`StorageSoc` 继续作为实时 SOC 的统一状态块，以设备名称匹配交流或直流储能。模拟台 SOC 积分与功率约束逻辑要从只查找 `DCGenerator` 扩展为同时查找 `ACGenerator`、`DCGenerator`：

- 优先使用实时量测 `SOC`。
- 没有实时 SOC 时可在页面显示 `model.e state_of_charge`，但该值只作为静态参考，不允许设备参加自动充放电控制。
- SOC 积分结果保持真实计算值，不强制裁剪到 0% 至 100%；控制器通过上下限策略暴露并纠正异常，而不是掩盖问题。
- 充放电效率继续按现有终端功率到电池内部功率的转换语义处理。

### 标准化储能行

后台将所有储能转换为统一结构，至少包含：

```text
side                    AC / DC
role                    grid_following / balance
dev_type                ACGenerator / DCGenerator
dev_name
set_type                p_set 或空
online
commandable
currentKw               有符号实时功率
soc / socKnown
socMin / socMax
capacityKwh
maxChargePowerKw
maxDischargePowerKw
chargePower             本周期允许的最大充电功率绝对值
dischargePower          本周期允许的最大放电功率
chargeMarginKw          相对当前值仍可增加的充电裕度
dischargeMarginKw       相对当前值仍可增加的放电裕度
commandKw               最终有符号目标
statusLabel
```

实时有功和 SOC 必须保持原符号、原数值，不对量测执行 `abs`、`max(0, value)` 或 `min` 修饰。只有在计算“可充/可放裕度”这类物理边界时才使用非负截断。

## 控制架构

控制周期仍由学员台 WEB 后台的单一新能源控制器执行。每一轮按以下阶段处理：

```text
接收状态与运行开关校验
  -> 读取同一仿真时刻的快照
  -> 标准化柴油、风光、ACDC、交流储能、直流储能和平衡储能
  -> 现有状态机生成 ACDC 与新能源候选目标
  -> 生成跟网储能侧级控制请求
  -> 按侧别优先级和设备裕度分配
  -> 统一执行 SOC、容量、步长、ACDC 传输和柴油预测校核
  -> 生成每台设备策略行、指标和决策日志
  -> 开环仅记录；闭环生成独立遥调指令并下发
```

每个仿真时刻最多执行并下发一轮策略。实时接收未启动、快照仿真时刻无效或与上一轮相同，本轮不计算、不下发。

## 跟网储能状态机

### 柴发高于下限死区

当在线柴发有功总和大于其下限总和加柴油死区时，形成放电请求：

```text
放电请求 = 柴发当前值 - (柴发下限 + 柴油死区内目标边界)
```

请求只按配置的储能/变流器控制步长渐进执行，不要求一轮完全消除偏差。仅 SOC 高于下限且有放电裕度的跟网储能可以参加。

交流跟网储能优先增加放电；交流侧用尽本轮可用裕度后，剩余请求分配给直流跟网储能。直流储能对交流侧柴油出力的影响还必须受在线 ACDC 变流器的 DC 向 AC 剩余传输能力限制。

### 柴发位于下限死区

当柴发出力位于下限死区内：

- 正常 SOC 区域内，跟网储能保持当前目标，不继续增加放电刺激柴发越过下限。
- SOC 已低于下限或放电降额边界时，只允许降低放电功率，不能增加放电。
- 不因为 SOC 偏低而主动生成负功率充电目标；正常充电仍必须有新能源富余来源。

### 柴发低于下限

当柴发低于下限时，先按步长减少所有跟网储能的正向放电，直至不再放电。若仍存在可验证的新能源富余，才允许形成负向充电请求；不能仅因为 SOC 较低就从柴油侧充电。

“新能源富余”只接受两类可验证来源：

1. 柴发当前出力低于下限所对应的系统富余功率。
2. 本轮计划恢复的新能源增量，并且该增量与新增储能充电量按 1:1 配对，保证组合动作不会抬高柴发出力。

因此：

```text
新增充电功率 <= 柴发下限偏低量 + 本轮配对的新能源恢复增量
```

任何无法解释来源的充电候选都在最终校核中归零。

### SOC 硬约束与线性降额

- `SOC >= soc_upper_limit`：该设备充电裕度为零；允许保持或增加放电。
- `SOC <= soc_lower_limit`：该设备放电裕度为零；允许减少放电；只有存在新能源富余时才允许充电。
- 上限附近按现有充电线性降额曲线收缩充电功率。
- 下限附近按现有放电线性降额曲线收缩放电功率。
- 能量裕度按控制周期折算，目标不得使预测 SOC 在单周期内越过 `model.e` 上下限。
- SOC 无效时，设备不参与自动控制，并在策略表与日志中说明原因。

## 侧别分配规则

### 放电分配

为降低柴发出力，跟网储能按以下顺序承担剩余放电请求：

1. 交流侧跟网储能。
2. 直流侧跟网储能。

直流侧分配量不得超过：

- 直流储能本身的放电裕度。
- 在线 ACDC 变流器 DC 向 AC 的剩余传输容量。
- 统一预测校核允许的剩余柴油修正量。

### 充电分配

为吸收新能源富余，跟网储能按以下顺序承担充电请求：

1. 直流侧跟网储能。
2. 交流侧跟网储能。

直流侧充电若需要通过 ACDC 从交流侧吸收功率，同样受 AC 向 DC 剩余传输容量限制；与同轮直流新能源恢复配对的本地充电不重复占用 ACDC 容量。

### 同侧多设备分配

同一侧多台储能不按设备数量简单平均，而按本轮可用裕度比例分配：

```text
设备分配量 = 侧级请求量 * 设备可用裕度 / 同侧可用裕度总和
```

分配后逐台执行容量、SOC、能量和步长裁剪。因舍入或单机边界留下的余量再按剩余裕度进行有限次再分配，最终总量不得超过侧级请求。

## 与 ACDC 平衡策略的协调

ACDC 变流器不是储能变流器，继续使用自己的 `p_ac_set` 指令；交流/直流跟网储能分别使用自己的 `p_set` 指令。禁止执行以下操作：

- 把 ACDC 候选功率与储能候选功率相加后写入 ACDC 指令。
- 把 ACDC 候选功率复制成某台储能的目标。
- 对 V/SLACK 平衡储能直接下发 `p_set`。

现有 ACDC 状态机先产生独立候选目标。统一校核器根据 ACDC 目标变化的预测效果计算尚未解决的柴油偏差和新能源富余，再限制跟网储能的侧级请求。这样既保留原有平衡储能控制，也避免 ACDC 与直接储能对同一偏差重复全额动作。

对直流跟网储能，ACDC 仅作为跨侧功率传输边界参与校核，不把两者目标合并为一条指令。

## 统一最终校核

状态机和分配器只产生候选目标，所有候选必须经过同一个最终校核器。校核顺序为：

1. 设备在线、控制模式和 `p_set` 点有效。
2. 当前有功、SOC 和边界数据有效。
3. 单机充放电功率上下限。
4. SOC 线性降额与单周期能量裕度。
5. 单周期控制步长。
6. ACDC 在线状态、方向和剩余传输能力。
7. 充电功率具有可验证的新能源富余来源。
8. ACDC 与跟网储能组合动作后的柴油预测边界。

只要本轮动作使柴发下限偏差缩小，且没有触发其他硬约束，就允许下发；不要求一个控制周期内完全达标。若组合动作会使原本合格的柴发越过下限，按剩余允许修正量等比例缩小本轮新增动作。

若校核后目标与当前值的差小于数值容差，不生成重复指令，但仍保留策略行和“保持”日志。

## 指令生成与仲裁

闭环模式下，每台直接可控跟网储能生成独立自动遥调：

```json
{
  "dev_type": "ACGenerator 或 DCGenerator",
  "dev_name": "模型设备名称",
  "set_type": "p_set",
  "set_value": "有符号目标功率"
}
```

- 自动指令继续使用现有可配置有效期，默认 120 分钟。
- 同一设备、同一 `p_set` 的新自动指令覆盖旧人工指令和旧自动指令。
- 开环模式不写入指令簿，只记录候选值、校核结果和未下发原因。
- 平衡储能没有直接指令；其策略行明确标记“由 ACDC 间接调节”。
- 单台设备缺少控制点时只禁用该设备，不阻断其他储能和新能源策略。

## 页面展示

新能源控制页的控制策略分页调整为：

```text
风电 | 光伏 | 交流储能 | 直流储能 | 平衡储能 | 柴发 | 变流
```

交流/直流储能表格至少显示：

- 设备名称。
- 遥调点名称。
- 当前功率。
- 目标功率。
- SOC。
- SOC 下限、上限。
- 当前允许充电功率。
- 当前允许放电功率。
- 控制状态/未参与原因。

平衡储能继续显示当前功率、SOC、边界和“由 ACDC 间接调节”，不显示可执行的 `p_set` 目标。

现有综合“储能功率”和“储能 SOC”指标保持，并明确采用所有在线储能的有符号功率总和与按能量容量加权的 SOC。趋势图中的储能当前值采用所有储能有符号总和；直接控制目标只汇总交流/直流跟网储能，不把 ACDC 目标重复计入储能目标。

## 日志与指标

每一轮日志至少说明：

- 柴发当前总功率、下限总和、死区和所属区域。
- 交流/直流跟网储能的在线数量、SOC 区域和可充/可放裕度。
- 放电或充电请求的来源及总量。
- ACDC 候选动作已承担的柴油修正量。
- 交流优先放电或直流优先充电的分配结果。
- 被 SOC、能量、步长、ACDC 容量或柴油预测校核裁剪的功率。
- 每台储能最终目标以及开环未下发、闭环已下发或保持不重复下发的结果。

新增统计指标：

- 交流跟网储能当前/目标功率。
- 直流跟网储能当前/目标功率。
- 跟网储能可充/可放总裕度。
- 本轮新能源富余充电预算及实际使用量。
- 因 ACDC 传输容量未能执行的直流储能功率。

## 后台与仿真支持边界

### 学员台后台

- `simu/renewable_control.py`：标准化三类储能、生成侧级请求、分配、统一校核、策略行和指令。
- `simu/server.py`：保持单例控制器和现有接收前置条件，并把新增储能分类、目标及指标纳入现有策略状态序列化。
- `simu/service.py`：快照 `device_parameters` 同时暴露 `ACStorageGen` 与 `DCStorageGen`。

### 模拟台运行数据

- `simu_loop.py`：储能定义、运行约束、实际功率快照和 SOC 积分同时支持 `ACGenerator` 与 `DCGenerator`。
- `simu/server.py`：模型包与储能来源行生成时保留 AC/DC 类型和引用关系。
- 现有 `StorageSoc`、量测定义和控制点命名保持兼容，不引入第二套 SOC 状态文件。

### 学员台页面

- `simu/web/trainee/index.html`：增加交流储能、直流储能和平衡储能分页入口及对应列。
- `simu/web/trainee/app.js`：识别新分类、渲染行、汇总指标和趋势数据。
- 样式沿用现有新能源策略表，不新增独立页面或新的控制线程。

## 异常处理

- `ACStorageGen` 引用不存在的 `ACGenerator`，或 `DCStorageGen` 引用不存在的 `DCGenerator`：该行标记模型引用无效，不参与控制。
- 控制模式不支持有功直控：归类为平衡/不可控储能，不下发。
- `p_set` 控制点缺失：显示“缺少遥调点”，不下发。
- SOC 量测缺失、无效或状态异常：显示静态 SOC 参考，但禁止自动控制。
- 充放电功率、容量或 SOC 上下限无效：只禁用该设备并记录模型告警。
- ACDC 全部离线或无对应方向容量：直流储能不得承担跨侧柴油修正；本地新能源与本地充电配对仍可执行。
- 快照在计算过程中失去接收状态：丢弃整轮结果，不产生部分指令。
- 任一设备目标不是有限数：该设备指令被丢弃并记录错误，其他设备继续处理。

## 测试设计

所有生产代码按测试驱动方式实施，每个行为先建立失败测试并确认失败原因。

### 模型与快照测试

1. `device_parameters()` 同时返回 `ACStorageGen`、`DCStorageGen`。
2. `ACStorageGen.idx_acgenerator` 正确解析到 `ACGenerator`。
3. AC/DC 同名风险通过 `dev_type + dev_name` 区分。
4. 旧模型没有 `ACStorageGen` 时快照保持兼容。
5. 模型中不存在的储能不会出现在策略表。

### 储能分类测试

1. AC P/PQ 模式且有 `p_set` 点归类为交流跟网储能。
2. DC P 模式且有 `p_set` 点归类为直流跟网储能。
3. V/SLACK 或无 `p_set` 点的储能归类为平衡/不可控储能。
4. 离线、SOC 未知或边界无效的设备不可下发。
5. 功率和 SOC 实时值保留原始符号，不被绝对值或零下限改写。

### 放电策略测试

1. 柴发高于下限加死区且 AC 储能有裕度时，AC 储能先按步长增加放电。
2. AC 裕度不足时，剩余请求分配给 DC 储能。
3. DC 储能请求受 ACDC DC 向 AC 剩余容量限制。
4. 同侧多台储能按放电裕度比例分配。
5. 柴发在下限死区内时，不增加储能放电。
6. 柴发低于下限时，先减少现有放电而不是反向充电。
7. SOC 达到下限的设备绝不增加放电。

### 充电策略测试

1. 有可验证新能源富余时，DC 储能优先增加充电。
2. DC 充电裕度不足时，剩余富余分配给 AC 储能。
3. 同侧多台储能按充电裕度比例分配。
4. 没有柴油下限偏低量或配对新能源恢复增量时，充电目标为零。
5. 低 SOC 本身不能触发柴油给储能充电。
6. SOC 达到上限的设备绝不增加充电。
7. 与新能源恢复配对的储能充电不会使预测柴发出力上升。

### 统一校核测试

1. ACDC 与跟网储能同时动作时，只允许承担剩余偏差，不重复全额修正。
2. 单步动作改善柴油偏差但未完全达标时仍允许下发。
3. 组合动作会越过柴发下限时按剩余修正量缩小。
4. SOC 线性降额、能量裕度和步长按最严格边界裁剪。
5. 无效数值、失去接收状态或重复仿真时刻不产生指令。
6. 每个仿真时刻最多下发一次策略。

### 指令与页面测试

1. AC 储能生成 `ACGenerator/<name>/p_set` 指令。
2. DC 储能生成 `DCGenerator/<name>/p_set` 指令。
3. 平衡储能不生成直接指令。
4. 开环只记录策略，闭环才下发。
5. 自动指令保持默认 120 分钟有效期并覆盖同点人工指令。
6. 页面分别展示交流、直流、平衡储能及遥调点名称。
7. 综合指标和曲线不把 ACDC 功率重复计入储能功率。

### 模拟台 SOC 回归测试

1. AC 跟网储能放电时 SOC 连续下降，充电时 SOC 连续上升。
2. DC 跟网储能保持现有 SOC 积分语义。
3. AC/DC 储能的实际终端功率用于 SOC 积分，而不是仅使用设定值。
4. SOC 结果不被裁剪到 0% 至 100%。
5. 储能离线或死岛时实际功率为零，SOC 不因陈旧功率继续积分。

## 验收标准

- 模型定义的 AC、DC 跟网储能均出现在学员台新能源策略表，模型未定义的设备不出现。
- 柴发高于下限死区时，AC 储能先放电，剩余请求才由受 ACDC 容量约束的 DC 储能承担。
- 有新能源富余时，DC 储能先充电，剩余富余再由 AC 储能承担。
- 同侧多机按可用裕度比例分配，不发生简单平均导致的单机越限。
- 无新能源富余时，不产生任何负功率充电策略；低 SOC 不会触发柴油充电。
- 任意目标均满足设备功率、SOC、能量、步长、ACDC 传输及柴油预测边界。
- ACDC、AC 储能、DC 储能各自收到独立指令，不做目标相加或复制。
- V/SLACK 平衡储能不收到直接 `p_set` 指令。
- 开环/闭环、每仿真时刻一次、接收前置条件和 120 分钟自动指令有效期保持有效。
- 模拟台与学员台对 AC/DC 储能当前功率、SOC、策略和指令显示一致。

## 非目标

- 不自动向 `model.e` 添加实际储能设备；设备必须由模型明确声明。
- 不改变潮流内核中 AC/DC 发电机的基本功率符号约定。
- 不把 ACDC 变流器解释为储能变流器。
- 不增加低 SOC 时由柴油主动给储能充电的应急模式。
- 不基于风速、太阳辐照度或负荷预测决定储能充放电。
- 不新增第二个新能源控制线程、页面级控制器或独立指令仲裁器。
